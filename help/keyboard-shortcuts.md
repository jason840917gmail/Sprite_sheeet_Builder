# Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+O` | Open an image |
| `Ctrl+S` | Save a project |
| `Ctrl+E` | Export the sprite sheet |
| `Ctrl+Shift+E` | Export individual tiles |
| `Ctrl+Z` | Undo the last bucket change |
| `Ctrl+Y` | Redo the last bucket change |
| `V` | Pointer tool |
| `G` | Grid tool |
| `B` | Paint Cleanup tool |
| `Space` | Add the current selection to the bucket |
| `Esc` | Clear the current source selection |
| `F1` | Open this help guide |

In Select mode, the arrow keys nudge the selection by one pixel. `WASD` pans the source view.

In Paint Cleanup mode, drag to apply the selected mode. Alt-click chooses a Clone Color source point.
