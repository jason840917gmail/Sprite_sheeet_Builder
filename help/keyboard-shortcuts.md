# Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+O` | Open an image |
| `Ctrl+S` | Save a project |
| `Ctrl+E` | Export the sprite sheet |
| `Ctrl+Shift+E` | Export individual tiles |
| `Ctrl+Z` | Undo the last bucket change |
| `Ctrl+Y` | Redo the last bucket change |
| `V` | Pointer tool |
| `G` | Grid tool |
| `B` | Paint Cleanup tool |
| `R` | Rotate the selected bucket tile |
| `Space` | Add the current selection to the bucket |
| `Esc` | Cancel an unapplied tile transform, or clear the current source selection |
| `F1` | Open this help guide |

In Select mode, the arrow keys nudge the selection by one pixel. `WASD` pans the source view.

In Paint Cleanup mode, drag to apply the selected mode. In Clone Color mode, Shift+left-click samples a pixel's exact RGB color; click or drag to paint it, and Shift-click again to replace the sample.

In Rotate mode, drag a corner or the center ring to rotate. Hold `Shift` to snap to 15-degree increments, drag the center dot to move the pivot, press `Enter` to apply, and press `Esc` to cancel unapplied changes.
