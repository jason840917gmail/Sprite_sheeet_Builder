# Video Workflow

1. Choose **File > Open Video** and set the frame range, sampling interval, and maximum frame count.
2. Extract candidate thumbnails, then select frames in the browser.
3. Click a frame to add it to the bucket, or use **Seed Animation** for a quick ordered set.
4. Set the output size and choose **Fit**, **Stretch**, or **Fill/Crop**.
5. Use the bucket to reorder, rename, duplicate, or remove frames.
6. Open **Animation Preview** to check the selected animation.
7. Export the transparent sprite sheet. Use **Export Frame Metadata** when the game needs source frame/timestamp information.

Multiple video tabs can share one bucket. Each tile keeps its source video, frame index, timestamp, and resize metadata so projects can be saved and reprocessed safely.
